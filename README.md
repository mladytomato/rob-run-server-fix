## 1. Базовые проверки

Прежде чем менять настройки, исключите очевидные проблемы.

1. **Проверьте статус серверов Rob Run.**  
   Игра находится в раннем доступе, возможны технические работы или сбои на стороне разработчиков. Загляните в официальные каналы игры или на сайты вроде [Downdetector](https://downdetector.com/).

2. **Полностью перезапустите Steam и игру.**  
   Не просто закройте окно, а выберите **«Steam» → «Выход»** в главном меню клиента. Затем запустите Steam снова и откройте игру из библиотеки.

3. **Убедитесь, что игра обновлена.**  
   В библиотеке Steam проверьте, нет ли для Rob Run ожидающих загрузки обновлений. Устаревшая версия клиента — частая причина ошибок подключения (например, E-0301/E-0302).

4. **Проверьте целостность игровых файлов.**  
   В Steam щёлкните правой кнопкой мыши по Rob Run, выберите **«Свойства» → «Установленные файлы» → «Проверить целостность игровых файлов»**. Это исправит повреждённые или отсутствующие файлы (помогает при ошибках E-0124, E-0303, E-0502).

## 2. Исправления через свойства Steam

Некоторые проблемы можно решить, добавив специальные команды в параметры запуска игры.

**Как это сделать:**  
В библиотеке Steam щёлкните правой кнопкой мыши по **Rob Run** → **«Свойства»** → в поле **«Параметры запуска»** введите нужную команду.

- **Принудительный запуск через Steam:**  
  Убедитесь, что игра запускается именно из библиотеки Steam, а не через ярлык `.exe`. Это важно для корректной работы античита и авторизации (помогает при ошибке E-0405).

- **Параметр `-novr`:**  
  Если игра без причины запускает SteamVR, добавьте эту команду, чтобы отключить автоопределение VR.

- **Параметр `-tcp`:**  
  Иногда помогает, если ваше соединение или провайдер имеют проблемы с UDP-трафиком. Эта команда заставляет Steam использовать протокол TCP, который может быть более стабильным в некоторых сетях.

- **Экспериментальные параметры (`-dx11`, `-force-d3d11`):**  
  Могут помочь при вылетах и проблемах с рендерингом.  
  > **Важно:** эти параметры не являются официальным решением для проблем с сетью, и их эффективность не гарантирована. Если вы их добавили и стало хуже — обязательно удалите.

## 3. Сетевые исправления на компьютере

Эти действия очищают сетевые кэши и сбрасывают настройки, которые могли накопить ошибки.

1. **Сброс сетевого стека и кэша DNS.**  
   Откройте командную строку **от имени администратора** (Пуск → `cmd` → «Запуск от имени администратора») и выполните по очереди следующие команды, нажимая Enter после каждой:

   ```bash
   ipconfig /release
   ipconfig /renew
   ipconfig /flushdns
   netsh winsock reset
   ```

   После выполнения последней команды **перезагрузите компьютер**.

2. **Отключите прокси-сервер.**  
   В Windows перейдите в **«Параметры» → «Сеть и Интернет» → «Прокси»** и убедитесь, что функция «Использовать прокси-сервер» выключена. Активный прокси или VPN может блокировать подключение к игровым серверам (помогает при ошибке E-0102).

3. **Смените DNS-сервер.**  
   Если ваш провайдер предоставляет нестабильные DNS-серверы, это может вызывать ошибки подключения. Попробуйте установить публичные DNS, например, от Cloudflare (`1.1.1.1` и `1.0.0.1`) или Google (`8.8.8.8` и `8.8.4.4`).

## 4. Настройки роутера (включая Ростелеком)

Проблема может быть на уровне вашего домашнего роутера. Эти настройки универсальны, но для роутеров, выдаваемых Ростелекомом, путь может немного отличаться.

**Как войти в настройки роутера:**  
Откройте браузер и введите IP-адрес роутера, обычно это `192.168.1.1` или `192.168.0.1` (точный адрес и логин/пароль указаны на наклейке на корпусе устройства).

1. **Перезагрузка роутера.**  
   Самое простое и часто эффективное действие. Отключите роутер от питания на 30–60 секунд, затем включите снова и дождитесь полной загрузки.

2. **Смена DNS на роутере (для Ростелеком и других).**  
   Это применит новый DNS ко всем устройствам в вашей сети.
   - В веб-интерфейсе роутера найдите раздел, связанный с настройками **WAN**, **«Интернет»** или **«Подключение»**.
   - Найдите настройки DNS. Отключите опцию автоматического получения DNS (например, «Получать DNS автоматически»).
   - Вручную впишите основной и альтернативный DNS-серверы (например, `1.1.1.1` и `1.0.0.1`).
   - Сохраните настройки и перезагрузите роутер.

3. **Проброс портов и брандмауэр.**  
   Убедитесь, что ваш роутер или антивирус не блокируют порты, необходимые для игры.
   - **Порты Roblox (могут быть актуальны и для Rob Run):**  
     Игра использует исходящие UDP-порты в диапазоне **`49152-65535`**. В настройках брандмауэра роутера убедитесь, что эти порты не заблокированы для вашего ПК.

4. **Специальные настройки для Ростелеком (продвинутый уровень).**  
   В некоторых случаях провайдер может применять фильтрацию трафика (DPI), которая мешает подключению к игровым серверам. Это сложная проблема, и её решение требует настройки специального ПО на роутере (например, `nfqws` или `zapret`).
   > **Внимание:** Этот метод требует продвинутых знаний и подходит только для роутеров с поддержкой установки стороннего ПО (например, Keenetic). Он заключается в добавлении правил для обхода DPI-фильтрации для IP-адресов Roblox/Rob Run. Пример команды для конфигурации:  
   > `--filter-udp=49152-65535 --dpi-desync=fake --dpi-desync-repeats=10 ...`  
   > **Не рекомендуется новичкам.**

## 5. Специфические ошибки Rob Run

Если вы видите конкретный код ошибки, эта таблица поможет сориентироваться.

| Код ошибки | Вероятная причина | Что делать |
| :--- | :--- | :--- |
| **E-0101 / E-0110** | Игра не получает данные от сервера. | Проверьте интернет, перезапустите Steam и игру. |
| **E-0201** | Потеря соединения с сервером во время игры. | Перезапустите игру, приостановите загрузки, попробуйте переключиться с Wi-Fi на кабель. |
| **E-0301 / E-0302** | Устаревшая версия игры. | Перезапустите Steam и установите обновления для Rob Run. |
| **E-0401** | Steam не может подтвердить ваш аккаунт. | Полностью закройте Steam и запустите его снова в онлайн-режиме, убедившись, что вошли в правильный аккаунт. |
| **E-0405** | Ошибка инициализации Steam. | Запускайте игру только из библиотеки Steam, а не через ярлык `.exe`. |
| **E-0501 / E-0502** | Проблема с античитом Easy Anti-Cheat. | Запустите игру через Steam и проверьте целостность файлов. Также проверьте, не блокирует ли антивирус файлы игры. |

## 6. Продвинутые и альтернативные методы

Если ничего из вышеперечисленного не помогло, можно попробовать следующее.

- **Использование игровых ускорителей (VPN/бустеров).**  
  Программы вроде LagoFast, UU Booster или аналогичные могут помочь, если проблема в неоптимальной маршрутизации до серверов игры. Они создают более стабильный туннель.  
  > **Важно:** используйте только проверенные сервисы и помните, что это может нарушать правила игры, если она запрещает VPN.

- **Смена региона в игре.**  
  В самой игре Rob Run, возможно, есть возможность сменить регион или сервер. Попробуйте переключиться на другой регион, чтобы найти более стабильное подключение.

- **Проводное соединение.**  
  Wi-Fi подвержен помехам. Если есть возможность, подключите компьютер к роутеру с помощью Ethernet-кабеля. Это обеспечит максимальную стабильность и низкий пинг.

## 7. Заключение

Проблемы с подключением в Rob Run могут быть вызваны множеством факторов: от банального сбоя на серверах до сложных сетевых настроек. Начните с базовых проверок и последовательно продвигайтесь по списку. Помните, что игра находится в раннем доступе, поэтому некоторые ошибки могут быть исправлены только разработчиками.

Если ни один из способов не помог, лучше всего обратиться в официальную службу поддержки игры, приложив скриншоты ошибок и описание выполненных действий.

## 🛠️ Automated Fix (Windows)

A ready-to-use batch script is provided in this repository: **`scripts/RobRunFix.bat`**

It automates the Windows-side steps from sections 1–4:
- IP release / renew / DNS flush
- Winsock + TCP/IP stack reset
- DNS switch to Cloudflare or Google (and back to DHCP)
- System proxy + WinHTTP proxy disable
- Optional Windows Firewall reset (with warning)

Just right-click → **Run as administrator** and select **`[6] Full Auto Fix`** for a one-shot repair.

> ⚠️ Router-level fixes (Rostelecom DNS, port forwarding, DPI bypass) still require manual configuration in your router's web interface — see section 4.
