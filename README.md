## 1. Базовые проверки

Прежде чем менять настройки, исключите очевидные проблемы.

1. **Проверьте статус серверов Rob Run.**  
   Игра находится в раннем доступе, возможны технические работы или сбои на стороне разработчиков. Загляните в официальные каналы игры или на сайты вроде [Downdetector](https://downdetector.com/).

2. **Полностью перезапустите Steam и игру.**  
   Не просто закройте окно, а выберите **«Steam» → «Выход»** в главном меню клиента. Затем запустите Steam снова и откройте игру из библиотеки.

3. **Убедитесь, что игра обновлена.**  
   В библиотеке Steam проверьте, нет ли для Rob Run ожидающих загрузки обновлений. Устаревшая версия клиента — частая причина ошибок подключения (например, E-0301/E-0302).

4. **Проверьте целостность игровых файлов.**  
   В Steam щёлкните правой кнопкой мыши по Rob Run, выберите **«Свойства» → «Установленные файлы» → «Проверить целостность игровых файлов»**. Это исправит повреждённые или отсутствующие файлы (помогает при ошибках E-0124, E-0303, E-0502).

## 2. Исправления через свойства Steam

Некоторые проблемы можно решить, добавив специальные команды в параметры запуска игры.

**Как это сделать:**  
В библиотеке Steam щёлкните правой кнопкой мыши по **Rob Run** → **«Свойства»** → в поле **«Параметры запуска»** введите нужную команду.

- **Принудительный запуск через Steam:**  
  Убедитесь, что игра запускается именно из библиотеки Steam, а не через ярлык `.exe`. Это важно для корректной работы античита и авторизации (помогает при ошибке E-0405).

- **Параметр `-novr`:**  
  Если игра без причины запускает SteamVR, добавьте эту команду, чтобы отключить автоопределение VR.

- **Параметр `-tcp`:**  
  Иногда помогает, если ваше соединение или провайдер имеют проблемы с UDP-трафиком. Эта команда заставляет Steam использовать протокол TCP, который может быть более стабильным в некоторых сетях.

> Полный список рекомендуемых и экспериментальных параметров — в [разделе 6](#6-параметры-запуска-steam).

## 3. Сетевые исправления на компьютере

Эти действия очищают сетевые кэши и сбрасывают настройки, которые могли накопить ошибки.

1. **Сброс сетевого стека и кэша DNS.**  
   Откройте командную строку **от имени администратора** (Пуск → `cmd` → «Запуск от имени администратора») и выполните по очереди следующие команды, нажимая Enter после каждой:

   ```bash
   ipconfig /release
   ipconfig /renew
   ipconfig /flushdns
   netsh winsock reset
   ```

   После выполнения последней команды **перезагрузите компьютер**.

2. **Отключите прокси-сервер.**  
   В Windows перейдите в **«Параметры» → «Сеть и Интернет» → «Прокси»** и убедитесь, что функция «Использовать прокси-сервер» выключена. Активный прокси или VPN может блокировать подключение к игровым серверам (помогает при ошибке E-0102).

3. **Смените DNS-сервер.**  
   Если ваш провайдер предоставляет нестабильные DNS-серверы, это может вызывать ошибки подключения. Попробуйте установить публичные DNS, например, от Cloudflare (`1.1.1.1` и `1.0.0.1`) или Google (`8.8.8.8` и `8.8.4.4`).

4. **DNS-over-HTTPS (DoH).**  
   Более современный и приватный способ DNS-запросов, который может обходить некоторые виды фильтрации трафика провайдером. В Windows 11: **Параметры → Сеть и Интернет → Свойства адаптера → Назначение DNS-сервера → Шифрование**. Укажите `1.1.1.1` (Cloudflare) или `8.8.8.8` (Google) и включите шифрование.

## 4. Настройки роутера (включая Ростелеком)

Проблема может быть на уровне вашего домашнего роутера. Эти настройки универсальны, но для роутеров, выдаваемых Ростелекомом, путь может немного отличаться.

**Как войти в настройки роутера:**  
Откройте браузер и введите IP-адрес роутера, обычно это `192.168.1.1` или `192.168.0.1` (точный адрес и логин/пароль указаны на наклейке на корпусе устройства).

1. **Перезагрузка роутера.**  
   Самое простое и часто эффективное действие. Отключите роутер от питания на 30–60 секунд, затем включите снова и дождитесь полной загрузки.

2. **Смена DNS на роутере (для Ростелеком и других).**  
   Это применит новый DNS ко всем устройствам в вашей сети.
   - В веб-интерфейсе роутера найдите раздел, связанный с настройками **WAN**, **«Интернет»** или **«Подключение»**.
   - Найдите настройки DNS. Отключите опцию автоматического получения DNS (например, «Получать DNS автоматически»).
   - Вручную впишите основной и альтернативный DNS-серверы (например, `1.1.1.1` и `1.0.0.1`).
   - Сохраните настройки и перезагрузите роутер.

3. **Проброс портов и брандмауэр.**  
   Убедитесь, что ваш роутер или антивирус не блокируют порты, необходимые для игры.
   - **Порты Roblox (могут быть актуальны и для Rob Run):**  
     Игра использует исходящие UDP-порты в диапазоне **`49152-65535`**. В настройках брандмауэра роутера убедитесь, что эти порты не заблокированы для вашего ПК.

4. **Специальные настройки для Ростелеком (продвинутый уровень).**  
   В некоторых случаях провайдер может применять фильтрацию трафика (DPI), которая мешает подключению к игровым серверам. Это сложная проблема, и её решение требует настройки специального ПО на роутере (например, `nfqws` или `zapret`).
   > **Внимание:** Этот метод требует продвинутых знаний и подходит только для роутеров с поддержкой установки стороннего ПО (например, Keenetic). Он заключается в добавлении правил для обхода DPI-фильтрации для IP-адресов Roblox/Rob Run. Пример команды для конфигурации:  
   > `--filter-udp=49152-65535 --dpi-desync=fake --dpi-desync-repeats=10 ...`  
   > **Не рекомендуется новичкам.**

5. **Настройка MTU (продвинутый уровень).**  
   Иногда проблемы вызваны слишком большим размером пакетов. Определите оптимальное значение командой `ping -f -l 1472 8.8.8.8` в cmd (уменьшайте число, пока пинг не пройдёт без фрагментации), затем установите это значение в настройках сетевого адаптера Windows (или роутера). Сложный, но иногда эффективный метод.

## 6. Параметры запуска Steam

Эти команды вводятся в свойствах игры в Steam (**ПКМ по игре → Свойства → Параметры запуска**). Они могут помочь, если проблема связана с рендерингом или сетевым протоколом.

**Рекомендуемые (безопасные) параметры:**

- **`-tcp`**: Иногда помогает, если ваш провайдер или оборудование испытывают проблемы с UDP-трафиком. Заставляет игру использовать протокол TCP, который может быть стабильнее в некоторых сетях.
- **`-window-mode exclusive`**: Запуск в эксклюзивном полноэкранном режиме. Может помочь при проблемах с переключением окон и стабильностью.
- **`-novr`**: Отключает автоопределение VR, если игра без причины запускает SteamVR.

**Экспериментальные параметры (использовать с осторожностью):**

- **`-dx11`** или **`-force-d3d11`**: Принудительный запуск через DirectX 11. Может решить проблемы совместимости на некоторых видеокартах.
- **`-NoShaderCompile`**: Пропускает этап компиляции шейдеров при запуске. Если игра зависает именно на экране «Preparing Shaders», этот параметр может помочь пройти дальше.

> **⚠️ Важное предупреждение:** Многие руководства советуют эти параметры, но эксперты сообщества отмечают, что они могут быть неэффективны или даже вредны. Если вы их добавили и ситуация ухудшилась или не изменилась — **обязательно удалите их**.

## 7. Драйверы и фоновые загрузки

Это база, но её часто игнорируют. Проблема может быть не в настройках сети, а в устаревшем ПО или перегруженном канале.

**Обновление драйверов:**

- **Драйвер видеокарты:** Устаревший драйвер GPU может вызывать ошибки при загрузке шейдеров и сбои подключения. Обновляйте драйверы **только** через официальные приложения производителей (NVIDIA GeForce Experience / NVIDIA App, AMD Adrenalin, Intel Arc Control). Не используйте «драйвер-паки» из непроверенных источников.
- **Драйвер сетевого адаптера:** Убедитесь, что драйвер вашей сетевой карты (Wi-Fi или Ethernet) актуален. Его можно обновить через «Диспетчер устройств» или скачав с сайта производителя материнской платы/ноутбука.

**Отключение фоновых загрузок:**

Перед запуском игры поставьте на паузу всё, что может «съедать» ваш интернет-канал:

- **Steam:** В настройках клиента (**Steam → Настройки → Загрузки**) включите опцию **«Не загружать во время игры»**. Это предотвратит скачивание обновлений для других игр, пока вы играете.
- **Другие приложения:** Закройте торрент-клиенты, приостановите синхронизацию в облачных хранилищах (OneDrive, Google Drive), закройте вкладки с активной загрузкой файлов в браузере.

## 8. Игровые бустеры (GearUP и аналоги)

Игровые бустеры — это специализированные сервисы, которые не просто меняют ваш IP, а **оптимизируют сетевой маршрут** от вашего компьютера до серверов игры. Они создают более стабильный «туннель» с меньшими потерями пакетов и пингом.

> Упоминание GearUP — **не реклама**, а просто популярный пример. Аналогично работают LagoFast, UU Booster, ExitLag и другие.

**Когда это может помочь:**

- Ваш провайдер неоптимально маршрутизирует трафик до игровых серверов (особенно если вы находитесь далеко от регионов EU или East US).
- Вы наблюдаете постоянные высокие пинги или потери пакетов, которые не решаются другими методами.

**Как это работает (на примере любого бустера):**

1. Установите приложение и создайте аккаунт.
2. Найдите **Rob Run** в списке поддерживаемых игр.
3. Выберите рекомендуемый сервер (обычно ближайший к вам или к игровому региону).
4. Нажмите «Ускорить» и запустите игру. Бустер автоматически перенаправит ваш трафик через оптимизированный маршрут.

**Важные моменты:**

- **Бустер — не панацея:** Он оптимизирует маршрут, но **не увеличивает пропускную способность** вашего канала. Если канал забит фоновыми загрузками, бустер не поможет.
- **Правила игры:** Использование бустеров может нарушать правила некоторых игр (хотя для Rob Run это маловероятно, так как она не запрещает VPN). Используйте на свой страх и риск.

## 9. Продвинутые и альтернативные методы

Если ничего из вышеперечисленного не помогло, можно попробовать следующее.

- **Смена региона в игре.**  
  У Rob Run есть два основных региона — **EU** и **East US**. Если вы не можете подключиться к одному, попробуйте переключиться на другой. Сделать это можно в настройках игры (вкладка **Other** → **Surrender to Feds**), что переместит вашего персонажа в тюрьму, откуда и происходит выбор сервера.

- **Проводное соединение.**  
  Wi-Fi подвержен помехам. Если есть возможность, подключите компьютер к роутеру с помощью Ethernet-кабеля. Это обеспечит максимальную стабильность и низкий пинг.

- **Настройка брандмауэра и антивируса.**  
  Зайдите в **«Безопасность Windows» → «Защита от вирусов и угроз» → «Журнал защиты»** и проверьте, не блокировались ли файлы из папки игры (особенно `GameAssembly.dll` или файлы Easy Anti-Cheat). Если такие записи есть — добавьте всю папку с игрой в список исключений антивируса и брандмауэра. **Не отключайте защиту полностью** — только добавьте игру в доверенные.

Проблемы с подключением в Rob Run могут быть вызваны множеством факторов: от банального сбоя на серверах до сложных сетевых настроек. Начните с базовых проверок и последовательно продвигайтесь по списку. Помните, что игра находится в раннем доступе, поэтому некоторые ошибки могут быть исправлены только разработчиками.

Если ни один из способов не помог, лучше всего обратиться в официальную службу поддержки игры, приложив скриншоты ошибок и описание выполненных действий.

## 🛠️ Automated Fix (Windows)

A ready-to-use batch script is provided in this repository: **`scripts/RobRunFix.bat`**

It automates the Windows-side steps from sections 1–4:
- IP release / renew / DNS flush
- Winsock + TCP/IP stack reset
- DNS switch to Cloudflare or Google (and back to DHCP)
- System proxy + WinHTTP proxy disable
- Optional Windows Firewall reset (with warning)

Just right-click → **Run as administrator** and select **`[6] Full Auto Fix`** for a one-shot repair.

> ⚠️ Router-level fixes (Rostelecom DNS, port forwarding, DPI bypass) still require manual configuration in your router's web interface — see section 4.

## 🔁 Auto-Retry Tool

**`scripts/RobRunAutoRetry.bat`** — an automated loop that reconnects to Rob Run every 30 seconds until the game process is running, then keeps watching it.

Features:
- Auto-launch Rob Run via `steam://rungameid/<APPID>` every `INTERVAL` seconds
- Detects and kills stuck `RobRun.exe` processes for a clean relaunch
- Pings `1.1.1.1` before each attempt, flushes DNS if the network is down
- **Escalation:** after 3 failures → full Steam restart; after 6 → Winsock/TCP-IP reset
- Audible beeps on launch and success
- Timestamped log in `RobRunAutoRetry.log`
- After success, monitors the process and re-enters the loop if the game crashes

### First-run setup

1. **Find the Steam AppID.** Open Rob Run's Steam Store page — URL looks like `store.steampowered.com/app/XXXXXXX`. The digits are the AppID.
2. **Find the game process name.** Launch Rob Run, open **Task Manager → Details**, and find the game's `.exe` (usually `RobRun.exe` or `RobRun-Win64-Shipping.exe`). Copy the exact name.
